✦ Nova

An audio feature extractor for C#: tempo, key, loudness, timbre and rhythm from any track.

dotnet add package StarFruit.Nova
var f = new Nova.FeatureExtractor().Extract(@"D:\Music\track.flac");

Console.WriteLine($"{f.Bpm:F1} BPM, {f.Key.Key} {f.Key.Scale}");
// 128.0 BPM, A minor

What it computes

GroupFields
RhythmBPM, beat positions
TonalKey, scale, strength, tuning, mean HPCP
LoudnessReplay gain, average loudness, dynamic complexity
Low-levelEvery frame-wise lowlevel descriptor: MFCC, GFCC, bands, spectral shape, contrast and more
Temporal (optional)Beat grid, per-beat rows, onset pattern, swing, syncopation, tempo drift, structure
DSPFFT, windows, mel/ERB filterbanks, a 32-band matched-biquad EQ

Descriptor names and statistics follow the AcousticBrainz low-level layout, so the output lines up with that dataset and anything trained on it.

Decoding

Nova analyses mono 44.1 kHz samples. Given a path, it decodes with ffmpeg. Given samples, it takes them from any decoder, such as NAudio on Windows Media Foundation, and needs no ffmpeg. See Getting Started.
