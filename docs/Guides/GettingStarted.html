Getting Started

Requirements

  • .NET 10
  • ffmpeg on PATH, or its path in NOVA_FFMPEG, only if Nova decodes files for you

Install

dotnet add package StarFruit.Nova

Extract a file

using Nova;

var extractor = new FeatureExtractor();
var f = extractor.Extract("track.flac");

f.Bpm;                                  // 128.0
f.Key;                                  // KeyResult { Key = "A", Scale = "minor", ... }
f.ReplayGain;                           // -9.3
f.LowLevel["mfcc"].Mean;                // double[13]
f.LowLevel["spectral_centroid"].Median; // double[1]

Audio input

Nova analyses mono float samples at 44.1 kHz, held in a MonoSignal.

CallNeedsNotes
Extract(path)ffmpegDecodes with AudioDecoder: soxr resampling and a channel average.
Extract(MonoSignal)NothingSamples from any decoder, such as NAudio on Windows Media Foundation.

Decoding with NAudio

NAudio's AudioFileReader decodes through Windows Media Foundation, so no ffmpeg is needed:

using NAudio.Wave;
using NAudio.Wave.SampleProviders;

using var reader = new AudioFileReader(path);

// Nova expects 44.1 kHz, so resample anything else
ISampleProvider source = reader.WaveFormat.SampleRate == 44100
    ? reader
    : new WdlResamplingSampleProvider(reader, 44100);

// Mix the channels down to mono by averaging them
int channels = reader.WaveFormat.Channels;
var mono = new List<float>();
var buffer = new float[16384 * channels];
int read;
while ((read = source.Read(buffer, 0, buffer.Length)) > 0)
    for (int i = 0; i + channels <= read; i += channels)
    {
        float sum = 0;
        for (int c = 0; c < channels; c++) sum += buffer[i + c];
        mono.Add(sum / channels);
    }

var f = extractor.Extract(new Nova.Audio.MonoSignal(mono.ToArray(), 44100));

Lossless 44.1 kHz files give the same samples with either decoder. Lossy files and other sample rates can come out slightly different, since the decoder and resampler differ.

Decode a window

With ffmpeg, only part of a file:

var decoder = new Nova.Audio.AudioDecoder(@"C:\tools\ffmpeg.exe");
var clip = decoder.Decode("track.flac", start: 30, seconds: 10);
