Temporal Features

var f = new FeatureExtractor(temporal: true).Extract("track.flac");
var t = f.Temporal!;

t.Validity.Status;            // Pulse
t.Pattern.Swing8;             // 0.12
t.Pattern.SyncopationOverall;
t.Tempo.Drift;
t.Structure.Sections;         // Section(StartBar, Bars, Start, Length)[]

The track-level values come out exactly the same with or without temporal.

Parts

TypeHolds
BeatGridBeats, bar starts, downbeat confidence (4/4)
BeatSequencePer beat: loudness, band onsets, flux, centroid, chroma, MFCC
OnsetPatternBars folded to 16 and 48 steps × 4 bands; swing, syncopation, clarity
TempoStabilityBeat spread, drift, local BPM range, changes, 64-point curve
BarStructure64×64 chroma and timbre self-similarity, novelty, sections, energy
ClockSeriesOne row a second: loudness, onsets, pulse salience, beat support, flatness
RhythmValidityPulse, Uncertain or NoPulse
