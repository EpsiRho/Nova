Equalizer

Up to 32 bands of matched biquads, with no high-frequency cramping near Nyquist.

using Nova.Dsp;

var settings = new EqualizerSettings
{
    Bands =
    {
        new EqBand { Type = EqBandType.LowShelf, Frequency = 80,   Gain = 3 },
        new EqBand { Type = EqBandType.Peak,     Frequency = 3000, Gain = -2, Q = 1.4 },
        new EqBand { Type = EqBandType.HighPass, Frequency = 25,   Slope = 24 },
    }
};
if (settings.Validate() is string error) throw new ArgumentException(error);

var eq = new Equalizer(settings, sampleRate: 44100, channels: 2);
eq.Process(interleaved);   // in place

Band types

TypeUses
PeakFrequency, Gain, Q
LowShelf / HighShelfFrequency, Gain
LowPass / HighPassFrequency, Slope
BandPass / NotchFrequency, Q

Limits

SettingRange
Frequency10 – 40,000 Hz
Gain, Preamp±30 dB
Q0.05 – 40
Slope6, 12, 18, 24, 36, 48 dB/oct

AutoHeadroom (on by default) lowers the output by the highest boost.

Plot the response

var freqs = Equalizer.LogFrequencies(256, 44100);
var db    = Equalizer.ResponseDb(settings, 44100, freqs);
