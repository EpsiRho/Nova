Onset & Mel Frames

Frame-level input for sequence models, 100 frames a second.

var clip = new AudioDecoder().Decode(path, start: 30, seconds: 8); // any MonoSignal works
FrameSeries onsets = BandOnsets.Compute(clip, BandOnsets.EightBandEdges);
FrameSeries mel    = MelFrames.Compute(clip);
ReadOnlySpan<double> frame = mel.Frame(100); // 1 s in
